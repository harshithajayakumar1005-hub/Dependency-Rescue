Dependency Rescue Algorithms Guide
1. Directed Graph: Tasks are nodes, dependencies are directed edges $u \rightarrow v$ representing finish-to-start constraints.
2. BFS (Breadth-First Search): Discovers direct dependent tasks at Level 1 and indirect dependent downstream tasks at Level 2+.
3. DFS (Depth-First Search): Traverses complete downstream chains and detects circular dependency back-edges.
4. CPM (Critical Path Method): Computes Earliest Start (ES), Earliest Finish (EF), Latest Start (LS), Latest Finish (LF), and Total Float = $LS - ES$. Tasks with Total Float = 0 define the Critical Path.
5. Delay Propagation Engine: Propagates hypothetical delay days across successors topologically without mutating saved database records.
6. AI Risk Engine: 11-feature Scikit-Learn Random Forest classifier + rule baseline predicting task delay probabilities, downstream BFS cascades, and autonomous recovery recommendations.
